# Arch Linux Dotfiles

Configuración personal de Arch Linux + Hyprland.

## Componentes principales

- Hyprland
- Noctalia Shell
- Hyprlock
- Hypridle
- SDDM
- Kitty
- Fish
- Firefox
- PipeWire
- NetworkManager
- power-profiles-daemon

## Atajos principales

| Atajo | Acción |
|---|---|
| Super + Space | Launcher |
| Super + A | Control Center |
| Super + V | Clipboard |
| Super + W | Firefox |
| Super + Enter | Kitty |
| Super + L | Bloquear |
| Super + Shift + W | Wallpapers |
| Super + Shift + D | Dev Launcher |
| Super + Alt + C | Menú de sesión |

## Estructura

- `.config/hypr` → Hyprland
- `.config/noctalia` → Noctalia
- `.config/kitty` → Kitty
- `.config/fish` → Fish
- `.local/bin` → scripts
- `.local/share/noctalia/plugins` → plugins propios
